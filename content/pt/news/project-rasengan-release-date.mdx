## Como os Anúncios de Data de Lançamento Costumam Acontecer

Projetos de jogos da comunidade tendem a seguir um pipeline reconhecível. Conhecer a sequência ajuda você a julgar se um novo post é um marco genuíno ou apenas conversa fiada.

| Fase | Sinal típico | O que significa para uma data de lançamento |
|---|---|---|
| 1. Conceito e protótipo | Capturas de tela, clipes curtos, devlogs | A data está a anos de distância, se é que existe |
| 2. Vertical slice | Loop completo de gameplay demonstrado | Pode existir uma meta interna, mas não anunciada |
| 3. Testes fechados | Inscrições, builds privadas, conversas sob NDA | A janela de lançamento está sendo finalizada |
| 4. Demo ou beta pública | Build para download, tópicos de feedback | A data se torna plausível em alguns meses |
| 5. Anúncio de lançamento | Post oficial com um dia específico | A data é real — mas ainda pode mudar |
| 6. Lançamento | Página na loja no ar, arquivos disponíveis para download | A data está definida |

A maioria dos rumores que você vê hoje está em algum ponto entre as fases um e três. Essa é exatamente a zona onde as datas são mais voláteis e menos confiáveis.

### O Padrão "Anuncia e Depois Adia"

Mesmo quando uma data é publicada, projetos da comunidade frequentemente escorregam. Um atraso de três meses é normal, não escandaloso. As razões costumam ser banais: um bug que aparece de última hora, um colaborador que se afasta ou uma revisão de plataforma que demora mais do que o esperado. Planeje-se para atrasos e você raramente se decepcionará.

## Sinais de Que uma Data de Lançamento É Genuína

Nem toda evidência tem o mesmo peso. Esta tabela classifica os tipos de fonte que você vai encontrar, da mais confiável à menos confiável.

| Tipo de fonte | Confiabilidade | Por quê |
|---|---|---|
| Página oficial do projeto ou conta verificada do desenvolvedor | Muito alta | Direta, responsável, citável |
| Cobertura da grande imprensa de games | Alta | Passa por checagem editorial antes de publicar |
| Listagem em loja com uma data | Alta | As plataformas exigem compromisso |
| Live ou Q&A do desenvolvedor | Média-alta | Espontâneo, mas ainda de primeira mão |
| Posts de moderadores no Discord ou fórum | Média | Pode ser preciso, mas geralmente é de segunda mão |
| Capturas de tela de posts apagados | Baixa | Fácil de fabricar ou interpretar errado |
| "Vazamentos" anônimos | Muito baixa | Sem responsabilidade, sem verificação |

Uma regra prática: se uma afirmação sobre a **data de lançamento de Project Rasengan** não puder ser rastreada até uma fonte de primeira mão, arquive-a como "possível" em vez de "confirmada". A experiência dos jogadores nessas comunidades mostra consistentemente que vazamentos com tom confiante estão errados muito mais vezes do que certos.

### Verificação Cruzada em Menos de Cinco Minutos

1. Abra a página oficial do projeto ou a conta verificada e analise os últimos dez posts.
2. Verifique se um veículo importante como a [IGN](https://www.ign.com/) cobriu a afirmação de forma independente.
3. Procure uma listagem em loja, que é a prova prática mais forte de um lançamento pretendido.
4. Pesquise a string exata da data mais "rumor" para ver se ela já foi desmentida.
5. Se todos os quatro passos não derem em nada, espere. Paciência não custa nada.

Seja cético. A experiência dos jogadores mostra que assets extraídos e vazamentos anônimos são frequentemente mal interpretados, desatualizados ou fabricados. Use-os, no máximo, como dicas, nunca como confirmação.
